## Delivered repair

RC3 recorded a terminal win but did not present clear next/replay actions. RC4 displays a full-screen accessible result panel, stops the completed attempt, clears held input and active Dash, and gives explicit large actions.

- Lava victory: Next: Storm Circuit, Play again, Choose stage.
- Storm victory: Play again and Choose stage. No third stage was added.
- Play again resets the attempt and starts it immediately in one activation; no second Start is required.
- Next opens the existing Storm stage with Practice or Time Challenge retained. Its Ready screen permits selection of the private character before Start.
- Missing stars: a visible remaining-star message appears; the player can still move and return for them. It is not a victory or frozen state.
- Game over: a distinct Try again panel offers checkpoint retry, a fresh attempt, or stage selection. Checkpoint retry in Challenge remains ineligible to replace a best record.
- Duplicate activation of a hidden result action is ignored. Result buttons support keyboard focus and native taps; gameplay shortcuts do not act behind the modal.
- RC4 records use separate keys from RC2/RC3, so the previous versions' best records are not overwritten.

The original V4.1 change handler is byte-identical to RC3. The private asset was neither available to these tests nor uploaded. Replay in the same page retains the selected model; navigating to another stage requires selecting the original file again locally. No automatic cross-page persistence is claimed. The hub and result panel explain this limitation.
