# تجربة قبول واحدة مجمعة — هاتف أو iPad

**المرشح:** Sky Rush V29 RC2، للمراجعة فقط. هذه تجربة مقترحة ولم تُنفّذ على جهاز حقيقي بواسطة فريق الاختبار.

## فتح المرشح دون نشر عام

نزّل أرشيف فرع المراجعة أو حزمة المراجعة المسلّمة، وفكّه على حاسوب. افتح الطرفية داخل المجلد الذي يحتوي `assets` و`review`، ثم شغّل خادم Python المحلي:

```bash
python -m http.server 8000 --bind 0.0.0.0
```

في Windows قد يكون الأمر `py -m http.server 8000 --bind 0.0.0.0`، وفي macOS أو Linux قد يكون `python3` بدل `python`.

صل الهاتف أو iPad بشبكة Wi-Fi نفسها. افتح في Safari أو Chrome:

```text
http://عنوان-IP-المحلي-للحاسوب:8000/review/v29/
```

استخدم عنوان الحاسوب المحلي الظاهر في إعدادات الشبكة. هذا رابط داخل الشبكة المحلية وليس نشرًا على GitHub Pages. افتح فقط مجلد المراجعة لهذا الاختبار، ثم أوقف الخادم بـCtrl+C عند الانتهاء. لا يكفي فتح ملفات HTML من مدير الملفات لأن تحميل وحدات المحرك يحتاج خادم HTTP.

## جلسة واحدة — نحو 10 دقائق

استخدم الجهاز نفسه طوال الجلسة، وسجّل نوعه وإصدار النظام والمتصفح. جرّب المرحلتين ضمن الجلسة نفسها.

1. افتح **Lava Rush** بوضع **Practice**. اختر ملف الفتاة V4.1 الأصلي المحلي إن كان متاحًا، ثم اضغط Start. سجّل نجاح ظهورها دون تغيير ملامحها؛ إن لم يكن الملف موجودًا فاكتب «الملف غير متاح».
2. على منصة البداية، اضغط سهم الحركة بالإصبع الأول، ثم اضغط **Pause** بالإصبع الثاني فورًا وأبقِ الأول مضغوطًا. يجب أن يتوقف اللاعب والعداد وتظهر Resume. ارفع الإصبعين وانتظر ثانيتين؛ يجب أن يبقيا متوقفين. اضغط Resume؛ يجب ألا تبدأ حركة تلقائية. كرّر ثلاث مرات.
3. حرّك اللاعب واقفز بالإصبع الثاني، ثم جرّب Dash. تحقق من استمرار الاتجاه حتى ترفع إصبع الحركة، ومن عدم بقاء زر مضغوط بعد رفع الأصابع. اعبر إلى نقطة حفظ، اسقط مرة، ثم جرّب Retry checkpoint. سجّل أي سقوط أو اندفاع غير متوقع.
4. أعد البدء، وقِس على منصة البداية نحو 20 ثانية بمؤقت مستقل مع مراقبة عداد اللعبة. ينبغي أن يتقاربا؛ سجّل القراءتين بدل الحكم من الذاكرة. أوقف اللعبة خمس ثوانٍ ثم استأنف: زمن الإيقاف لا يدخل في عداد اللعب. إذا ظهر توقف تلقائي بسبب انقطاع طويل، سجّله وافصل فترة الإيقاف من المقارنة.
5. أوقف اللعب قبل تدوير الجهاز، ثم استأنف في الاتجاه الآخر وكرّر الحركة مع Pause والقفز. انتقل إلى **Storm Circuit**، وجرّب **Time Challenge**، ثم كرّر الإيقاف بإصبع ثانٍ والحركة والقفز وDash والعودة لنقطة الحفظ.

لا يلزم افتعال بطء الجهاز أو فتح تطبيقات إضافية. تحقق انخفاض معدل الإطارات الاصطناعي موثق في اختبارات المتصفح؛ هذه الجلسة تكشف سلوك الجهاز الفعلي ولا تقيس وحدها تطابق جميع معدلات الإطارات.
